# Learnings (from my earlier sessions; source: history/board/team/synthetic/debriefs/)

- A scripted check can mislead (a locator that re-resolves after a click looked like a bug): test twice before filing.
- Trace a finding to its cause in the build before naming an owner (a desk file the build did not read; a script loaded twice).
- An owner's "done" must be measured on a phone as well as a desktop (a hover tooltip is not a fix).
- The re-measure is cheap and mechanical: do it before every reader run.
- Print field names only and filter every sgit command's output: tools print secrets of their own accord.
- A hit shown only as a count hides the reader: keep the persona's own words in the finding.
- This session: the container had no ssh-keygen (apt-get install openssh-client fixes it), and a shallow clone of the website needs a bounded deepen (depth 12000) to get the full history of my paths.
